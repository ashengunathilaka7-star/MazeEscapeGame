# Maze Escape Game

A pixel-style maze adventure game developed using Python and Pygame.

## Features

- Hold arrow keys or WASD to move continuously
- Randomly generated maze for each mission
- Wall collision detection
- Key and locked door system
- Collect three crystals along the route to unlock the exit
- Earn bonus points for collecting crystals
- 50 missions across 5 story chapters
- Score system

## Requirements

- Python 3
- Pygame 2.6.1

## Installation

Install Pygame:

```powershell
pip install pygame
```

## Run the Game

```powershell
python main.py
```

## Controls

- Hold Arrow Keys or WASD: Move
- SPACE: Next mission
- ESC: Exit game
