\# Maze Escape Game



A pixel-style maze adventure game developed using Python and Pygame.



\## Features



\- Player movement using arrow keys or WASD

\- Randomly generated maze for each mission

\- Wall collision detection

\- Key and locked door system

\- Exit and mission completion

\- 50 missions

\- 5 story chapters

\- Score system



\## Requirements



\- Python 3

\- Pygame 2.6.1



\## Installation



Install Pygame:



pip install pygame



\## Run the Game



python main.py



\## Controls



\- Arrow Keys / WASD: Move player

\- SPACE: Next mission

\- ESC: Exit game
